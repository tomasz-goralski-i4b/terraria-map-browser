# Proposed follow-up issues from the assets spike (#72)

Issue drafts written by the spike that produced [docs/assets.md](../assets.md). Check the backlog before filing.

```markdown
**Status:** filed as #73 (open).

## Goal
The reference .NET codec decodes a Terraria tile/wall texture (.xnb) into width, height and RGBA pixels, or a precise error.

## Scope
- XNB header, LZX chunk framing and bitstream (verbatim, aligned, uncompressed blocks), type-reader table and
  `Texture2D` payload exactly as in docs/assets.md.
- Synthetic XNB builders (uncompressed; LZX with uncompressed and literal-only verbatim blocks) and the negative vectors.
- Opt-in integration test driven by `TERRARIA_CONTENT` (skipped when unset).
- `.gitignore`: `*.xnb` ignored except generated fixtures.

## Out of scope
- Rendering, sprite layout, TS decoder, mod assets.

## Ownership
- dotnet/ (new assets project + tests), .gitignore

## Spec
- docs/assets.md ("XNB container", "LZX as used in XNB", "Test strategy")

## Compatibility impact
- Vanilla: Render (preparation)
- Modded worlds: None

## Acceptance criteria
- Synthetic uncompressed and LZX (uncompressed blocks, multi-chunk) files decode to the expected pixels.
- A literal-only verbatim LZX stream decodes to the expected pixels.
- Every negative vector in docs/assets.md returns its documented error.
- With `TERRARIA_CONTENT` set, all `Tiles_0…753` and `Wall_1…366` decode with consistent sizes; unset → skipped.

## Proof
- Test command: `bash scripts/verify.sh`
- Manual test: run the integration test with `TERRARIA_CONTENT` pointing at a local install.
```

```markdown
**Status:** filed as #74 (open).

## Goal
The .NET reference renderer maps a region of a world to sheet rectangles for blocks and walls.

## Scope
- Frame-important tiles: source rectangle `(frameX, frameY, textureGrid)`.
- Base self-framing for non-frame-important blocks (four-neighbour case always `B2`–`B4`; the diagonal-sensitive
  rules are out of scope) and 4-neighbour wall framing with variant `(7x + 11y) mod 3` (0–2 only).
- Worked examples 1–6 of docs/assets.md ("Sprite layout") as unit tests on rectangles (no pixels).

## Out of scope
- Blending between tile types, slopes, grass, gemspark 8-way, trees, animation, paint, lighting.

## Ownership
- dotnet/ (renderer project + tests)

## Spec
- docs/assets.md ("Sprite layout")

## Compatibility impact
- Vanilla: Render
- Modded worlds: None

## Acceptance criteria
- Worked examples 1–6 give the documented rectangles.

## Proof
- Test command: `bash scripts/verify.sh`
- Manual test: local render into `local-renders/` with `TERRARIA_CONTENT` set.
```
