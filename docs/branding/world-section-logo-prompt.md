# World-section logo revision

The user found the initial M monogram too weak beside the illustrations. The replacement shows a grass-and-earth world section inside blue editing corners, a cave-shaped opening and a detached tile. The same source drives the toolbar mark, favicons and PWA install icons.

Generated with the built-in ImageGen tool. Master: `mark-world-section-master.png`. Runtime images are resized with Lanczos; alpha is preserved. Maskable and Apple install icons use charcoal backing and safety margins. No tests were run, as requested by the user.
